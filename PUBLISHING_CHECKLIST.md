# Basin Nexus NG public release checklist

- [ ] Dedicated GitHub repository exists (NOT an existing, unrelated GIS portfolio repository)
- [ ] GitHub Pages enabled for main / root and build is green
- [ ] Approved and non-sensitive geographic data only
- [ ] No signed attendance pages, personal identifiers, private source docs or confidential Drive URLs
- [ ] Current naming and 20-catchment geometry validation checked
- [ ] Evidence and asset flags remain out of public distribution until approved
- [ ] Source attribution and institutional publication authority confirmed
- [ ] Site functional tests pass on desktop and mobile
- [ ] Live URL HTTP 200, no missing `data/` assets, no console errors
- [ ] Link and commit SHA communicated to project owner

If any privacy or rights item fails, publish only vetted placeholders and do not publish internal review data.
