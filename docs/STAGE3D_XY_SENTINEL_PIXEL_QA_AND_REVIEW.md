# Basin Nexus NG — Stage 3D-X/Y: actual optical pixel sampling and review-only visual matrix

**29 October 2026.** This combined stage advances the previous Stage 3D-W *metadata-only* scene discoveries to an **attempted bounded retrieval of Sentinel-2 image and scene-classification pixels**, followed by source-labelled visual reviewer aids. Pixel download success is measured by a separate post-merge GitHub Actions artifact; do not claim independent interpretation or facility confirmation based solely on passing synthetic tests.

## What remains fully protected

The confirmed dam site collection remains **zero**. The original CC BY 4.0 bonndata source inventory has **189** compiled source points over 20 simplified catchments, including **71 source-named / 118 source-unnamed**, while the 186 point opt-in research-only map excludes 3 disputed source identities. No stakeholder material is used and the public evidence catalogue remains zero approved records. Source names and published research point coordinates are **not independently verified dam facility facts**. "Unnamed reference point" is categorically different from an independently verified "Unnamed dam." No public map layer is modified.

## Two compatible stages in one automation

**3D-X pixel source extraction.** Inputs: the Stage W main-branch reviewer-only artifact containing 5 identified, still-unverified source reference IDs, checked publisher DOI/hash/ODbL lineage and 2019/2026 Sentinel-2 C1 L2A scene metadata. For every site/epoch, the script attempts the two lowest scene-cloud catalogue candidates in order; the STAC item must match its recorded ID and return **public** HTTPS COG assets \`visual\` (10m-derived true-colour) and \`scl\` (Scene Classification Layer). Reject non-approved hosts, unknown imagery formats and inconsistent source metadata.

The script uses pinned rasterio/GDAL with bounded remote COG windows, no downloading full 110 km Sentinel tiles, and renders approximately **720 × 720 m context** centered on the compiled reference, resampled to a 96 × 96 pixel *display chip*. The crosshair marks the **original compiled reference location, not a dam wall**. The Sentinel-2 SCL is separately read and co-registered using nearest-neighbor sampling, while the RGB display uses bilinear resampling. Scene-level cloud percentages from STAC are not used as local cloud measurements.

Compute simple pixel coverage and SCL metrics for the whole window and the central 25 × 25 display pixels: valid coverage, obscured classes 3/8/9/10/11, and cloud-clear class subset 4/5/6/7. SCL water class 6 is only a **satellite classifier observation about water**, never evidence of a constructed dam wall. No radiometric comparison between 2019 and 2026 is claimed: Sentinel-2 Level-2A baseline/offset changes can complicate direct cross-era reflectance comparisons. Display RGB is intended for human inspection only.

**3D-Y automatically generated review package.** A contact sheet \`STAGE3D_Y_REVIEW_BOARD_UNVERIFIED.png\`, five reference/epoch RGB image chips where successful, machine-readable \`stage3d_xy_pixel_qa_NOT_CONFIRMED.json\`, and a Markdown reviewer matrix are archived together. Missing data, cloud obstruction, or absent imagery downloads are labelled **PIXELS_UNAVAILABLE_NOT_NO_IMAGERY**, never "no dam". All reviewer confirmation fields remain false or null. Neither this pipeline nor its visual results can authorize public facility publication. Only a later accountable engineering/EO/field review, with a defensible physical wall position and uncertainty, source independence and release rights could support a separate reviewed PR.

## Licence separation and bounded resource use

Original Kouassi et al. (2026) compiled source: CC BY 4.0, DOI https://doi.org/10.60507/FK2/YLDK1Y . OSM way histories: © OpenStreetMap contributors, ODbL https://www.openstreetmap.org/copyright . Satellite imagery: **Contains modified Copernicus Sentinel data**, accessed via [Element 84 Earth Search](https://github.com/Element84/earth-search) and Sentinel-2 C1 L2A public Cloud-Optimized GeoTIFF assets. This is a review-only mixed-source derivative and is **not** silently integrated into the public CC BY reference map.

The on-main source workflow validates the publisher inputs and all Stage U–W gates before Stage X/Y. It installs pinned \`rasterio==1.4.3\`, \`numpy==2.2.6\` and \`Pillow==11.3.0\` only during main-branch pixel execution, archives outputs for 30 days and maintains the same strict public site file allowlist. Pull requests run **synthetic tests only** for source identity, metadata, URL allowlist, SCL semantics, no invented confirmations, duplicates and unavailability states. Independent browser QA runs the same pure safety checks. No private SCMP stakeholder source is read or copied to the external STAC service.

**Interpretation limits:** A colored image chip at a compiled point is not a survey, a measured structure coordinate, a construction date, a current operating-status determination or independent source-lineage evidence. Pixel coverage and SCL water fractions are model-derived quality/context diagnostics, not a structural-dam inventory or validation accuracy. A human reviewer must interpret the actual pixels and compare independent engineering and historical field/EO evidence before any claim of facility existence.
